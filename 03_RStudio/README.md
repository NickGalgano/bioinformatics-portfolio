## About This Module

This section of my bioinformatics portfolio contains the submitted files for the RStudio assignment completed in BIOL 2406 at Northeastern University.

The assignment introduced RStudio and the R programming environment through guided tutorials and exercises. The submitted files document the completed swirl modules, along with R Markdown work on data visualization and the apply family of functions.

This README provides an overview of the submitted files, describes their purposes and locations, and outlines the organization of the module submission.
